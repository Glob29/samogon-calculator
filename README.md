# Калькулятор самогонщика

Веб-калькулятор для домашнего винокурения: разбавление спирта водой с учётом контракции, расчёт сахаристости и крепости браги, контроль брожения по Brix, головы и хвосты по абсолютному спирту, ориентировочные сроки брожения.

Работает офлайн — один статический сайт без сборки и зависимостей. Достаточно открыть `index.html`.

**Языки интерфейса:** русский, English, 中文. Переключатель — в шапке, выбор запоминается в браузере.

## Что умеет

**Разбавление спирта.** Вводите исходную крепость, объём и желаемую крепость — получаете точный объём воды. Считается по балансу массы спирта через табличные плотности водно-спиртовых растворов при 20 °C, поэтому учитывается сжатие смеси (контракция). Для сравнения показывается и «простая» формула, которой пользуется большинство калькуляторов.

Пример: 1 л спирта 90 % → 40 %. Простая формула даёт 1,25 л воды, точный расчёт — 1,30 л (таблица Фертмана для этих значений даёт ≈1,31 л).

**Сахарная брага.** Гидромодуль, сахаристость сусла, ожидаемая крепость браги, объём браги, выход абсолютного спирта и самогона 40 %, срок брожения с поправкой на температуру. Предупреждает о пересахаре, слишком коротком или длинном гидромодуле, опасной температуре.

**Brix / рефрактометр.** Показание рефрактометра переводится в плотность, сахар в литре, выход спирта. Отдельный блок — контроль хода брожения по двум замерам: поправка на спирт по формуле Террилла, накопленная крепость и остаточный сахар с выводом «готово / ещё бродит».

**Головы и хвосты.** Расчёт от абсолютного спирта: сколько отобрать голов, сколько останется на тело, сколько уйдёт в хвосты — в литрах АС и в миллилитрах жидкости при типичной крепости фракции.

**Сроки брожения.** Справочная таблица по шести видам сырья с температурным коэффициентом.

**Поправка ареометра на температуру.** Спиртомер калиброван на 20 °C, и в тёплой жидкости он врёт в большую сторону. Вводите показание и температуру — получаете истинную крепость, величину поправки и таблицу для 5–35 °C. Для 40 % об. при 25 °C поправка ≈ −2,7°, при 30 °C — ≈ −5,5°: ощутимо, если разбавлять «по прибору».

Иконки у каждого раздела, тёмная тема, адаптив под телефон, работа без интернета.

## Формулы

### Разбавление

Масса безводного этанола сохраняется:

```
m₁ · w₁ = m₂ · w₂
```

где `m` — масса раствора, `w` — массовая доля спирта. Крепость в объёмных процентах переводится в массовую долю через плотность раствора:

```
w = v · ρ(этанол) / ρ(раствор)
```

Плотности берутся из таблицы при 20 °C с интерполяцией. Отсюда объём воды:

```
Vводы = (m₂ − m₁) / ρ(воды)
```

### Брага

```
сахаристость, % = сахар / (сахар + вода) · 100
крепость браги, % ≈ 0,6 · сахаристость
абсолютный спирт, л ≈ 0,6 · сахар, кг
самогон 40 %, л = абсолютный спирт / 0,4
гидромодуль = вода / сахар
```

Коэффициенты — практические для домашнего винокурения: теоретический максимум из 1 кг сахарозы ≈ 0,68 л АС, реально получается 0,55–0,6 л. Готовый выход ниже расчётного на 10–15 % из-за отбора голов и хвостов.

### Brix

```
SG           = 1 + B / (258,6 − B/258,2 · 227,1)
сахар, г/л   = SG · B · 10
крепость, %  ≈ 0,6 · B
```

В ходе брожения спирт искажает показатель преломления, поэтому текущий Brix пересчитывается с поправкой Террилла по паре замеров (начальный и текущий), а остаточный сахар оценивается как `(SG − 1) · 2600` г/л.

### Фракции

```
АС        = V · C
головы    = АС · k_голов      (объём жидкости = АС_фракции / крепость_фракции)
хвосты    = АС · k_хвостов
тело      = АС − головы − хвосты
```

Типичные крепости фракций: головы 78 %, тело 70 %, хвосты 25 %. Доли голов и хвостов зависят от сырья и аппарата: сахарная брага — 5–8 % на головы, зерновая — 8–10 %.

### Поправка ареометра на температуру

Ареометр плавает по плотности: в тёплой жидкости он тонет глубже, поэтому показывает больше, чем есть. Находим истинную крепость `c`, при которой плотность раствора при температуре замера равна плотности раствора с показанием `r` при 20 °C:

```
ρ₂₀(c) · (1 − α(c)·(T − 20)) = ρ₂₀(r)
```

`α(c)` — коэффициент объёмного расширения раствора (вода 0,00021; 40 % об. — 0,00093; 96 % об. — 0,00116 на °C). Уравнение решается бисекцией.

Результат ориентировочный (≈ ±0,5°): точные таблицы приведения — ГОСТ 8.315. Лучший способ вообще не пользоваться поправкой — дать жидкости принять комнатную температуру.

## Запуск в Windows

Самый простой способ — двойной клик по файлу **`Калькулятор самогонщика.lnk`** в папке проекта: откроется браузер, ярлык с иконкой реторты.

Запасные варианты:

- **`Запустить.cmd`** — то же самое, работает даже если папку переместили (путь берётся от самого файла).
- **`index.html`** — просто открыть в браузере, установка не нужна.
- Локальный сервер (не обязателен, удобен для DevTools): `python -m http.server 8000` → http://localhost:8000.

Сборка не нужна: чистые HTML, CSS и JavaScript, без внешних библиотек и CDN.

## Иконка

Иконка — медная реторта со змеевиком и каплей. Исходник один: `tools/make_icon.py`, из него генерируются все форматы.

```
assets/icon.svg        векторный исходник (открывается в браузере и Inkscape)
assets/icon-256.png    превью и apple-touch-icon
assets/icon-64.png      превью для мелких размеров
assets/icon-32.png      превью фавикона
assets/icon.ico        многоразмерная иконка (16–256) для ярлыка Windows
```

Пересобрать после правок:

```
python tools/make_icon.py
```

Геометрия задана в координатной сетке 256×256: `POT_BOX`, `DOME_BOX`, `NECK`, `COIL` — меняйте координаты и перезапускайте скрипт. Требуется Pillow (`pip install pillow`).

### Ярлык и почему иконка копируется в профиль

```
powershell -ExecutionPolicy Bypass -File tools\install-shortcut.ps1 -Desktop
```

Скрипт копирует `icon.ico` в `%LOCALAPPDATA%\SamogonCalculator\` и создаёт ярлыки (в папке проекта и, с ключом `-Desktop`, на рабочем столе).

Копия в профиле нужна не для красоты: проект лежит внутри рабочей папки DeepSeek Harness, а на неё навешаны защитные ACL — Проводник не может прочитать `.ico` оттуда и молча рисует стандартный значок «файл». Из профиля пользователя иконка читается нормально.

Если поменяли `.ico`, а ярлык показывает старое — перезапустите скрипт и нажмите F5 на рабочем столе. Совсем упорный кеш лечится перезапуском Проводника.

## Точность

Плотности заданы с шагом 5 % массовой доли и интерполируются линейно — погрешность порядка ±1 %, что на практике меньше ошибки бытового ареометра.

Крепость нужно измерять при 20 °C: при отклонении на 10 °C показания ареометра уходят на 2–3 градуса.
