# Boosty: регистрация и оформление страницы

Пошаговая инструкция плюс готовые тексты. Регистрация занимает 10–15 минут и требует только телефон и карту.

## Что понадобится

- телефон для SMS;
- почта (лучше отдельная, проектная);
- карта для выплат — Boosty запросит её при выводе денег;
- аватар: `assets/icon-512.png` уже готов.

## Шаг 1. Регистрация

1. Откройте https://boosty.to
2. Нажмите **«Стать автором»** (или «Войти» → «Создать аккаунт»).
3. Войдите через VK ID, Google или по e-mail. Быстрее всего VK ID, если он есть.
4. Подтвердите телефон кодом из SMS.
5. Подтвердите e-mail.

## Шаг 2. Страница автора

Название и описание — это то, что человек увидит первым. Готовые варианты:

**Название:**

> Калькулятор самогонщика

**Короткое описание (до 100 символов):**

> Бесплатные калькуляторы для домашнего виноделия и дистилляции. Без рекламы.

**Раздел «О проекте»:**

> Я делаю открытые калькуляторы для тех, кто занимается домашним вином и дистилляцией.
>
> Что уже есть: разбавление спирта с учётом сжатия смеси, расчёт сахарной браги, Brix и контроль брожения по рефрактометру, головы и хвосты по абсолютному спирту, поправка показаний спиртомера на температуру. Пять языков, работа офлайн, без рекламы и регистрации.
>
> Проект бесплатный и открытый (лицензия MIT): https://github.com/Glob29/samogon-calculator
>
> Поддержка идёт на домен, хостинг и время на новые инструменты. Если калькулятор сэкономил вам вечер — спасибо.

**Категория:** «Образование» или «Технологии». Не выбирайте алкогольную тематику — там строже модерация.

**Аватар:** `assets/icon-512.png`. **Обложка:** можно скриншот приложения.

## Шаг 3. Уровни подписки

Не обязательно делать много. Три — достаточно:

| Уровень | Цена | Что обещаете |
|---|---|---|
| **Спасибо** | 100 ₽/мес | Доступ к постам о том, что делаю дальше |
| **Спонсор** | 300 ₽/мес | То же + голосование за следующий калькулятор |
| **Меценат** | 1000 ₽/мес | То же + имя в README проекта |

Плюс включите **разовую поддержку** любой суммой — многие донатят один раз, а не подписываются.

## Шаг 4. Первый пост

> **Что это и зачем**
>
> Сделал калькулятор для домашнего винокурения. Началось с раздражения: все онлайн-калькуляторы разбавления считают по формуле, которая не учитывает сжатие смеси, и на 90 → 40 дают ошибку почти в полтора градуса.
>
> Теперь там шесть инструментов: разбавление, брага, Brix, фракции, поправка спиртомера, сроки брожения. Пять языков, работает офлайн, ставится на телефон как приложение.
>
> Ссылка: https://glob29.github.io/samogon-calculator/
>
> Проект бесплатный и останется бесплатным — код открыт. Поддержка нужна на домен и хостинг, чтобы уйти с github.io на нормальный адрес.
>
> Если пользуетесь — напишите, какой калькулятор добавить следующим.

## Шаг 5. Вставить ссылку в проект

Когда страница создана, скопируйте её адрес (вида `https://boosty.to/ваш-ник`) и замените заглушку в `support.html`:

```html
<a class="btn" id="boosty-btn" href="https://boosty.to/ВАШ_НИК" ...>
```

После этого — `git add -A && git commit -m "Добавить ссылку на Boosty" && git push`.

## Ограничения Boosty, о которых стоит знать

- **Алкогольная тематика.** Boosty не приветствует продвижение алкоголя. Проект — про расчёты и оборудование, поэтому риски низкие, но не публикуйте посты вида «как гнать дома» и не обещайте «алкоголь безопасен». Формулировки — про инструменты.
- **Выплаты.** Деньги приходят на карту; Boosty удерживает комиссию, точный процент смотрите в кабинете при подключении выплат.
- **Налоги.** Доход с платформы — это доход. Для регулярных сумм стоит оформить самозанятость; при разовых донатах вопрос обычно не возникает, но ответственность на вас.
- **Модерация контента.** Посты проходят проверку, откровенно рекламные тексты про алкоголь могут скрыть.

## Как понять, работает ли

На сайте клик по кнопке уже отправляется как событие `support_click` в аналитику. Значит видно:

- сколько людей дошли до страницы поддержки;
- сколько из них нажали кнопку;
- из какого канала они пришли (UTM).

Boosty покажет свою статистику по донатам. Сопоставив, вы поймёте, какая площадка даёт не просто визиты, а готовность платить.

Ориентир: 1 % посетителей, нажавших «поддержать», — нормальный результат для бесплатного инструмента.
