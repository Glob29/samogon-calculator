# Монетизация и замер результатов

Документ для себя: что запущено, какие метрики смотреть и по каким правилам решать, что работает.

## Что уже есть в проекте

| Канал | Что сделано | Файлы |
|---|---|---|
| Поисковый трафик | 4 посадочные страницы под запросы, sitemap, robots, FAQ-разметка | `content/seo-pages.js`, `tools/build-seo.js`, `*.html` |
| Приложение | PWA: манифест, офлайн через service worker, установка на телефон | `manifest.webmanifest`, `sw.js` |
| Аналитика | События в `window.dataLayer`, поддержка Яндекс.Метрики, UTM | `assets/analytics.js` |
| Донат | Страница поддержки с реквизитами-заглушками | `support.html` |

## Шаг 1. Включить счётчик

В `index.html` (и в шаблоне посадочных) замените:

```html
<script>window.SAMOGON_CONFIG = { ymId: null, debug: false };</script>
```

на свой номер счётчика Яндекс.Метрики:

```html
<script>window.SAMOGON_CONFIG = { ymId: 12345678, debug: false };</script>
```

и добавьте сам код счётчика перед `</head>`. События уже отправляются как `reachGoal`, цели в Метрике создадутся автоматически при первом срабатывании.

Проверка: откройте консоль, выполните `track('test')` — в `dataLayer` появится запись.

## Шаг 2. UTM-схема

Единые метки, чтобы сравнивать каналы:

```
utm_source = yandex | google | vk | telegram | youtube | habr
utm_medium = organic | social | referral | video
utm_campaign = <slug страницы или название поста>
```

Пример: `https://glob29.github.io/samogon-calculator/?utm_source=telegram&utm_medium=social&utm_campaign=launch`

Метки сохраняются в `sessionStorage` и прикладываются ко всем событиям — видно, какой канал дал не просто визит, а реальное использование калькулятора.

## Шаг 3. События и что они значат

| Событие | Смысл | Зачем |
|---|---|---|
| `tool_open` | открыл вкладку калькулятора | какие инструменты интересны |
| `calc_used` | реально менял значения (не чаще раза в 30 с) | настоящая польза, а не случайный вход |
| `preset_use` | нажал пресет «90 → 40» | какие сценарии массовые |
| `lang_change` | переключил язык | нужен ли EN/ZH |
| `support_click` | ушёл на страницу доната | конверсия в поддержку |
| `install_pwa` | установил как приложение | готовность ставить на телефон |

## Шаг 4. Что сравнивать через 4 недели

| Вопрос | Метрика | Порог решения |
|---|---|---|
| Работает ли SEO | визиты из поиска на посадочные | > 100/мес на страницу → делать ещё 10 таких |
| Что используют | доля `calc_used` от `tool_open` | < 20 % → интерфейс не понятен, править |
| Нужен ли английский | доля `lang_change` на en | > 10 % → переводить лендинги |
| Готовы ли ставить | `install_pwa` / визиты | > 3 % → публиковать в RuStore |
| Есть ли желание платить | `support_click` | > 1 % → включать донаты и партнёрки |

## Правила решений

1. **Не монетизировать то, что не используют.** Сначала `calc_used`, потом ссылки и донаты.
2. **Одна гипотеза за раз.** Меняем либо страницу, либо оффер — иначе непонятно, что сработало.
3. **Смотреть на absolutes, не на проценты.** 2 визита и 1 донат — это не 50 % конверсии.
4. **Партнёрки — только после 3–5 тыс. визитов в месяц.** Раньше это просто не окупит возни с маркировкой.

## Юридические заметки (РФ)

- Домашнее самогоноварение для личного потребления разрешено; продажа произведённого алкоголя — нет.
- Реклама алкоголя запрещена. Реклама **оборудования** пока разрешена: законопроект о её запрете Госдума отклонила в первом чтении в январе 2026. Ситуация может измениться — перепроверяйте перед запуском рекламы.
- Интернет-реклама подлежит маркировке (`erid` через ОРД). Партнёрская ссылка — тоже реклама.
- Возрастная маркировка 18+ на всех страницах уже стоит.

## Что делать дальше (по приоритету)

1. Подключить счётчик и посмотреть первые данные.
2. Добавить 6–10 страниц под запросы: «сколько градусов в браге», «таблица разбавления самогона», «гидромодуль 1 к 5», «сколько сахара на 30 литров».
3. Установить связь страниц: из статьи в калькулятор с предзаполнением (механика уже есть через `SEO_PRESET`).
4. После 3 тыс. визитов — первый партнёрский блок с пометкой «реклама».
5. После 5 тыс. — сборка APK для RuStore (см. `docs/ru-store.md`).
