# Публикация в RuStore / Google Play

Приложение уже готово как PWA: есть манифест, иконки, офлайн-режим. Осталось упаковать в APK/AAB.

## Что понадобится

| Для RuStore | Для Google Play |
|---|---|
| аккаунт разработчика (физлицо — бесплатно) | аккаунт $25 разово |
| подписанный APK | подписанный AAB |
| иконка 512×512, скриншоты | то же + политика конфиденциальности |

Java и Android SDK на этой машине не установлены — сборку надо делать либо в облаке, либо после установки JDK.

## Вариант A: PWABuilder (без установки чего-либо)

1. Откройте https://www.pwabuilder.com
2. Введите адрес: `https://glob29.github.io/samogon-calculator/`
3. Нажмите **Package for stores** → **Android**
4. Заполните:
   - Package ID: `ru.glob29.samogon`
   - App name: `Калькулятор самогонщика`
   - Short name: `Самогон`
   - Signing key: **Create new** (скачайте keystore — потеряете, потеряете возможность обновлять приложение)
5. Скачайте архив: внутри `.apk` (для RuStore) и `.aab` (для Google Play) + `assetlinks.json`.

## Вариант B: bubblewrap (нужен JDK 17+)

```bash
npm i -g @bubblewrap/cli
bubblewrap init --manifest https://glob29.github.io/samogon-calculator/manifest.webmanifest
bubblewrap build
```

На вопросы отвечайте:
- Application name: `Калькулятор самогонщика`
- Package ID: `ru.glob29.samogon`
- Signing key: создать новый, пароль сохранить

## Digital Asset Links (обязательно для TWA)

Чтобы приложение открывалось без адресной строки, положите файл
`assetlinks.json` по адресу `/.well-known/assetlinks.json` на сайте.

Для GitHub Pages это делается так: создайте папку `.well-known` в корне репозитория,
положите туда `assetlinks.json` из PWABuilder и запушьте. GitHub Pages отдаёт
файлы из корня, поэтому адрес будет:

```
https://glob29.github.io/samogon-calculator/.well-known/assetlinks.json
```

Проверка:

```bash
curl -I https://glob29.github.io/samogon-calculator/.well-known/assetlinks.json
```

## RuStore: порядок действий

1. Регистрация: https://console.rustore.ru — физлицо, нужен паспорт/ИНН для верификации.
2. **Создать приложение** → название, категория «Инструменты», возрастной рейтинг 18+.
3. Загрузить APK, заполнить карточку: описание, скриншоты (минимум 2), иконка 512×512.
4. Указать, что приложение бесплатное, без встроенных покупок (пока).
5. Отправить на модерацию — обычно 1–3 рабочих дня.

**Важно про тематику:** приложения, связанные с алкоголем, модерация проверяет внимательнее. Формулируйте описание как **калькулятор и справочник**, без призывов к употреблению, с пометкой 18+ и дисклеймером о вреде алкоголя (он уже есть в футере).

## Иконки и скриншоты

- Иконка 512×512: `assets/icon-512.png` — готова.
- Скриншоты: сделайте 3–4 с телефона (разбавление, брага, ареометр) или с десктопа в мобильном режиме DevTools.

## Обновления

После правок сайта:

1. Поднимите версию кеша в `sw.js` (`samogon-v1` → `samogon-v2`) — иначе пользователи останутся на старой версии.
2. Запушьте в `main` — Pages пересоберётся.
3. Для стора: `bubblewrap update && bubblewrap build`, загрузите новую версию с тем же keystore.
